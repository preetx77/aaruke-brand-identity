# Aarukè | Headless Luxury E-Commerce

> A bespoke, high-performance headless e-commerce storefront for the luxury jewelry brand **Aarukè**.

This project demonstrates a modern decoupled architecture, connecting a custom, high-fidelity **React** frontend with **Shopify's** powerful backend via the Storefront GraphQL API. It features a premium UI/UX with glassmorphism, smooth scroll-reveal animations, and an editorial design system tailored for luxury branding.

## ✨ Key Features

- **Headless Architecture:** Fully decoupled frontend utilizing Shopify's Storefront API for inventory, product data, checkout, and customer management.
- **Premium UI/UX:** 
  - Glassmorphism effects and radial gradients.
  - Editorial typography system (*Cormorant Garamond* for headings, *Inter* for body).
  - Scroll-reveal animations for an immersive browsing experience.
- **Secure Authentication:** Custom user portal for login and registration, interacting directly with Shopify's customer database via GraphQL mutations.
- **Dynamic Cart System:** 
  - Animated, slide-out cart drawer.
  - Real-time price calculation and quantity management.
  - Seamless redirect to Shopify's secure, hosted checkout.
- **Mobile-First Design:** 
  - App-like mobile navigation with an intuitive hamburger menu.
  - Expansive, editorial layouts optimized for desktop screens.

## 🛠 Tech Stack

| Category | Technology |
| :--- | :--- |
| **Frontend** | React.js (via Vite) |
| **Styling** | Tailwind CSS |
